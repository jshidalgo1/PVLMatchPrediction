# PVL Match Prediction Dashboard

A modern Next.js dashboard for visualizing Philippine Volleyball League tournament predictions, player statistics, and playoff brackets.

## 🚀 Quick Start

### Prerequisites

- Node.js 18+ and npm
- Dashboard data file (`public/data.json`) generated by the backend

### Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the dashboard.

### Build for Production

```bash
npm run build
npm start
```

## 📊 Features

### Tournament Overview
- **Current Standings**: Live tournament standings with win/loss records
- **Projected Standings**: Final standings after simulating remaining matches
- **Tournament Progress**: Visual indicator of tournament phase

### Player Statistics
- **Top Players Table**: Sortable player statistics across all skill categories
- **Per-Set Averages**: Block, Serve, Dig, Reception, and Set stats shown as averages per set
- **Total Stats**: Total Points and Attack Points shown as cumulative totals
- **Dynamic Sorting**: Click any metric to sort players by that stat
- **Tournament Filtering**: Stats filtered to current tournament (PVL REINFORCED CONFERENCE 2025)

Available Metrics:
- Total Points (total)
- Attack Points (total)
- Block Points (per-set average)
- Serve Points (per-set average)  
- Digs (per-set average)
- Receptions (per-set average)
- Sets (per-set average)

### Match Predictions
- **By Phase**: Predictions organized by tournament phase (Preliminary, Quarterfinals, Semifinals, etc.)
- **Confidence Scores**: Win probability for each predicted match
- **Actual vs. Predicted**: Distinguish between completed and simulated matches

### Playoff Bracket
- **Visual Bracket**: Complete tournament bracket from quarterfinals to champion
- **Matchup Details**: Team matchups with predicted winners
- **Confidence Indicators**: Color-coded confidence levels
- **Third Place Match**: Includes prediction for 3rd place game

## 🗂️ Data Structure

The dashboard consumes `public/data.json` with the following structure:

```typescript
{
  tournaments: [
    {
      id: number
      code: string
      name: string
      simulation: {
        current_standings: TeamStanding[]
        final_standings: TeamStanding[]
        predictions_by_phase: PhaseMatch[]
        playoffs: {
          quarterfinals: Match[]
          semifinals: Match[]
          championship: Match
          third_place: Match
          top_8_seeds: Seed[]
        }
      }
      history: {
        champion: string | null
        all_matches: HistoricalMatch[]
        phases: Phase[]
      }
    }
  ]
  players: PlayerStats[]
  teams: Team[]
  last_updated: string
}
```

## 🔄 Updating Dashboard Data

Dashboard data is generated by the Python backend:

```bash
# From project root
python scripts/export_dashboard_data.py
```

This creates/updates `dashboard/public/data.json`.

The dashboard automatically refreshes when `data.json` changes during development.

## 🛠️ Development

### Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm start` - Start production server
- `npm run lint` - Run ESLint

### Adding New Features

1. Update TypeScript types in `src/types/index.ts`
2. Modify `src/app/page.tsx` or add new components
3. Update backend `export_dashboard_data.py` if data structure changes
4. Test with sample `data.json`

## 🐛 Troubleshooting

### Dashboard shows "No data available"
- Ensure `public/data.json` exists
- Run `python scripts/export_dashboard_data.py` from project root
- Check console for JSON parsing errors

### Player stats not displaying
- Verify `data.json` contains `players` array
- Check that `player_id` is populated in database
- Ensure `sets_played > 0` for players

### Bracket not showing
- Confirm `simulation.playoffs` exists in data
- Run simulation with `--save_outputs` flag
- Re-export with `export_dashboard_data.py`

## 📝 Notes

- Dashboard is read-only; all data comes from backend
- Player stats filtered to current tournament (TEST_PVLR25)
- Per-set averages calculated as `stat / sets_played`
- Bracket uses latest simulation file from `outputs/` directory
